# COUP (เกมนักโค่นอำนาจ) - Cyberpunk Intrigue Edition

เกมการ์ดแนวบลัฟ จับโกหก และหักเหลี่ยมยอดนิยม **COUP** (โค่นอำนาจ) พัฒนาขึ้นมาใหม่ในรูปแบบ Single Player Web App สำหรับเล่นบนบราว์เซอร์ แข่งขันกับผู้เล่นบอท AI 3 คนที่มีความสามารถและสไตล์การเล่นเฉพาะตัวแตกต่างกัน

ตัวเกมถูกออกแบบมาในสไตล์ **Cyberpunk & Royal Gold Theme** ที่ดูหรูหรา ทันสมัย มีลูกเล่นเอฟเฟกต์เสียงสังเคราะห์ (Web Audio API Synthesizer) โดยไม่ต้องดาวน์โหลดไฟล์เสียงเพิ่ม และรองรับการแสดงผลทุกหน้าจอ (Responsive Design)

---

## 📂 โครงสร้างโปรเจกต์ (Vite + React Migration)
* `src/context/GameContext.jsx` — เอนจินควบคุมสถานะของเกม (State Machine) และการเชื่อมต่อ WebSocket
* `src/components/` — คอมโพเนนต์ UI แบบแยกส่วน (StartupOverlay, PokerTable, PlayerPod, Card, HistoryLog, Overlays)
* `src/utils/sound.js` — ตัวสร้างเสียงสังเคราะห์เอฟเฟกต์ด้วย Web Audio API
* `src/index.css` — ดีไซน์สไตล์มืด (Cyberpunk & Royal Gold Theme) และแอนิเมชันที่สวยงาม
* `server.cjs` — เซิร์ฟเวอร์ WebSocket สำหรับห้องเล่นออนไลน์หลายคน (Multiplayer Backend)
* `README.md` — คู่มือข้อมูลเกมและการทดสอบเล่น

## 🎮 สไตล์การเล่นของ AI (บอทคู่ต่อสู้)
ในบอร์ดเกมนี้คุณจะได้ประลองกับ AI 3 ตัวที่มีบุคลิกแตกต่างกันอย่างชัดเจน:
1. **AI 1 (ดุดัน - Aggressive)**: ชื่นชอบการปล้นเหรียญและส่งนักฆ่าลอบสังหาร มักอ้างสิทธิ์การ์ดโกหกบ่อยครั้ง และชอบท้าทายผู้เล่นอื่นเพื่อเร่งจังหวะเกม
2. **AI 2 (รอบคอบ - Cautious)**: เน้นการรับรายได้ปกติและการเสียภาษีอย่างปลอดภัย ไม่ชอบบลัฟโกหก และจะบล็อกการกระทำเมื่อมีการ์ดจริงในมือเท่านั้น
3. **AI 3 (เจ้าเล่ห์ - Opportunistic)**: ปรับกลยุทธ์ตามผู้เล่นที่กำลังนำอยู่ มักพยายามบลัฟเพื่อหาทางแซง หรือท้าทายผู้เล่นที่ร่ำรวยเป็นพิเศษ

## 📖 สรุปกฎกติกาการเล่น COUP
ผู้เล่นแต่ละคนจะเริ่มต้นด้วย **2 เหรียญ** และการ์ด **2 ใบ (อิทธิพล)** หากการ์ดของคุณถูกกำจัดจนครบ 2 ใบ คุณจะพ่ายแพ้และถูกคัดออกทันที เป้าหมายคือเป็นคนสุดท้ายที่ยังคงเหลืออิทธิพลอยู่

### การกระทำทั่วไป (ไม่ต้องอ้างสิทธิ์การ์ด)
* **รายได้ปกติ (Income)**: หยิบ 1 เหรียญจากกองกลาง (บล็อกไม่ได้/ท้าทายไม่ได้)
* **ความช่วยเหลือจากต่างชาติ (Foreign Aid)**: หยิบ 2 เหรียญจากกองกลาง (ท้าทายไม่ได้ แต่อาจโดนบล็อกโดยผู้เล่นอื่นที่แกล้งอ้างว่าเป็น "ดยุก")
* **รัฐประหาร (Coup)**: จ่าย 7 เหรียญ บังคับให้เป้าหมาย 1 คนเลือกทำลายการ์ดตัวเอง 1 ใบ (บล็อกไม่ได้/ท้าทายไม่ได้) *หากมีเหรียญ 10 เหรียญขึ้นไปเมื่อเริ่มเทิร์น ต้องใช้ Coup เท่านั้น!*

### การกระทำเฉพาะตัวละคร (ท้าทายได้โดยผู้เล่นอื่น)
* **เก็บภาษี (Tax - อ้างสิทธิ์ ดยุก 👑)**: หยิบ 3 เหรียญจากกองกลาง
* **ลอบสังหาร (Assassinate - อ้างสิทธิ์ นักฆ่า 🗡️)**: จ่าย 3 เหรียญเพื่อส่งนักฆ่าไปทำลายการ์ดของเป้าหมาย 1 ใบ (เป้าหมายสามารถขัดขวางโดยอ้างเป็น "คอนเตสซา")
* **ปล้น (Steal - อ้างสิทธิ์ กัปตัน ⚔️)**: ขโมยเหรียญ 2 เหรียญจากเป้าหมาย (เป้าหมายสามารถบล็อกโดยอ้างเป็น "กัปตัน" หรือ "ทูต")
* **เจรจาเปลี่ยนการ์ด (Exchange - อ้างสิทธิ์ ทูต 📜)**: จั่วการ์ด 2 ใบจากกองกลาง มาเลือกสลับกับการ์ดในมือ

### การท้าทาย (Challenge ⚡)
เมื่อมีผู้เล่นอ้างสิทธิ์ตัวละครเพื่อทำคำสั่งหรือบล็อก ผู้เล่นอื่นสามารถกด **ท้าทาย (Challenge)** ได้:
* **ถ้าผู้กระทำมีตัวละครนั้นจริง**: แสดงการ์ดนั้นให้ทุกคนดู สับเข้ากองการ์ดเพื่อจั่วใบใหม่ แล้วเล่นคำสั่งนั้นต่อ จากนั้น **ผู้ท้าทายจะต้องเสียการ์ดอิทธิพลไป 1 ใบ**
* **ถ้าผู้กระทำโกหก (บลัฟ)**: ผู้กระทำจะถูกจับได้ และ **ต้องเสียการ์ดอิทธิพลไป 1 ใบ** เพื่อรับผิดชอบ การกระทำนั้นจะถูกยกเลิกทันที

## 🚀 วิธีการทดสอบและรันโปรเจกต์

### 1. ติดตั้ง Dependencies และรันแอปพลิเคชัน
ติดตั้งไลบรารีที่จำเป็นทั้งหมด:
```bash
npm install
```

### 2. รันแอปพลิเคชันสำหรับเล่นคนเดียว (Development Server)
รัน Vite Dev Server ในเครื่องโลคัลของคุณ:
```bash
npm run dev
```
หลังจากรันคำสั่ง ระบบจะเปิดลิงก์ http://localhost:5173/ เพื่อให้คุณเข้าเล่นเกมบนเบราว์เซอร์ได้ทันที!

### 3. รันเซิร์ฟเวอร์ Multiplayer (เมื่อต้องการเล่นออนไลน์)
หากต้องการทดสอบโหมดเล่นหลายคนออนไลน์ (Multiplayer) ให้เปิดเทอร์มินัลอีกหน้าต่างและรันคำสั่ง:
```bash
npm run server
```
เซิร์ฟเวอร์จะเปิดใช้งานบนพอร์ต 8080 (`ws://localhost:8080`) จากนั้นสามารถเปิดเบราว์เซอร์ 2 หน้าต่างคู่กันเพื่อเข้าห้องและทดสอบเชื่อมต่อพร้อมกันได้

### 4. คอมไพล์โปรเจกต์เพื่อพร้อมสำหรับการ Deploy (Build)
สร้างโปรเจกต์เวอร์ชัน Production:
```bash
npm run build
```
ไฟล์สำหรับ Deploy จะถูกบันทึกไว้ในโฟลเดอร์ `dist/` ซึ่งพร้อมนำขึ้นไปโฮสต์บน **GitHub Pages** หรือโฮสติ้งอื่น ๆ ได้อย่างรวดเร็ว

สนุกไปกับสงครามจิตวิทยาและการชิงไหวชิงพริบในเกม COUP! ⚖️👑
